# Docs

This directory holds companion materials that are useful for understanding the
project but are not the paper or the benchmark harness themselves.

## Visual Guide

- [OrchestraBench Visual Study Guide](./orchestrabench-visual-study-guide.html)

This HTML page is a reader-friendly companion to the paper and repository. It
is best for:

- onboarding a new teammate
- walking a manager or collaborator through the project quickly
- preparing a short presentation on the benchmark's core findings

Important notes:

- The paper in [paper/main.pdf](../paper/main.pdf) remains the source of truth.
- The HTML page is interpretive and explanatory, not a separate results source.
- GitHub's file viewer shows HTML source code rather than rendering the page, so
  this guide is best opened locally in a browser or later served through GitHub
  Pages.
